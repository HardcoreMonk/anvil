# ephemera v0.5.0-v0.7.0 core service parity review

## 상태

- 검토일: 2026-07-06 (sync branch 검증 완료일)
- upstream 범위: cross-phase `v0.4.0`..`v0.7.0` (git-diff base `v0.3.6..v0.7.0`).
  `v0.4.0`-`v0.4.5` 상세 채택 근거는
  [`docs/analysis/10-v0.4.0-v0.4.5-runtime-stabilization-adoption.md`](10-v0.4.0-v0.4.5-runtime-stabilization-adoption.md)에,
  이 문서는 `v0.5.0`-`v0.7.0`을 중심으로 하되 전 태그를 하나의 cross-phase parity
  matrix로 종합한다.
- anvil branch: `sync/ephemera-v0.7-core-service-parity` (HEAD `8f0fea2` 시점 문서 반영)
- 기준: ephemera core service 100% runtime/operator support. anvil은 upstream ephemera
  `v0.7.0`을 token redaction, tenant/egress, scheduler, audit, IronClaw MCP surface
  separation 적응 위에서 지원한다.
- upstream tag 목록(`git tag --list 'v0.*'`): `v0.4.0` `v0.4.1` `v0.4.2` `v0.4.3`
  `v0.4.4` `v0.4.5` `v0.5.0` `v0.5.1` `v0.5.2` `v0.5.3` `v0.5.4` `v0.5.5` `v0.6.0`
  `v0.6.1` `v0.6.2` `v0.6.4` `v0.7.0` (upstream에 `v0.6.3` 없음).

## 분류 기준

| 상태 | 의미 |
|---|---|
| `adopted` | upstream 그대로 채택, anvil 고유 수정 없음 |
| `adapted` | runtime 가치는 채택하되 public/security surface를 anvil 정책에 맞게 수정 |
| `deferred` | 가치는 있으나 현재 scope 밖 또는 기본 비활성 (별도 검증/설계 필요) |
| `excluded` | anvil 경계와 충돌해 채택하지 않음 (의도적 divergence) |

## 결론

- upstream parity scope(`v0.4.0`-`v0.7.0`)의 모든 upstream feature가 위 matrix에서
  `adopted`/`adapted`/`deferred`/`excluded` 중 하나로 분류됐다. blank row 없음.
- anvil runtime/operator baseline supports upstream ephemera v0.7.0 with anvil
  adaptations for token redaction, tenant/egress, scheduler, audit, and IronClaw MCP
  surface separation.
- `v0.5.0`-`v0.7.0`은 더 이상 미검토 backlog가 아니라 병합·적응·검증된 baseline이다.
- deferred(parity-review 시점 기록; 위 matrix 행은 그 시점 사실): `v0.4.0` auto-snapshot
  public support, `v0.4.2` default COW 전환, `v0.4.4` flock broadcast의 MCP tool 노출,
  `v0.5.3` flock member per-profile sizing 존중. 2026-07-11~13 결정으로 전부 종결/갱신:
  auto-snapshot은 env-only 확정(공개 표면 미노출), broadcast MCP 노출은 기각 확정
  (daemon-only 유지), flock member per-profile sizing 존중은 완료. default COW 전환은
  **종결**(2026-07-13 — default plain 무기한 확정, COW opt-in; burn-in 4라운드로 anvil-측
  소진, 근본은 anvil 밖 KVM/fc resume-race, fc v1.16.1 최대 완화, D4는 upstream 추적;
  `docs/ADR_INDEX.md` v0.4.2 행).
- excluded(의도적 divergence): flock `agent_tokens` response exposure, 46c orphan-delete
  semantics(anvil `409`), upstream keep-alive pooled proxy client(anvil
  `DisableKeepAlives`), runtime MCP Gateway의 IronClaw 표면 승격(비목표).
- release-gate 코드 항목(audit-writer sentinel, stdio stderr scrub,
  `credential_env` reserved names, production-mux auth assert, broadcast unit
  test, GC fail-closed 정렬)은 2026-07-06 follow-up batch(`4a802f5`..`0625df5`)로
  닫혔다. 상세 gate/handoff는 Phase 1-4 handoff
  ([`docs/operations/2026-06-10-...`](../operations/2026-06-10-ephemera-v0.4-runtime-sync-handoff.md) …
  [`2026-07-06-...`](../operations/2026-07-06-ephemera-v0.7-parity-sync-handoff.md))에 있다.
- **2026-07-06 post-v0.4.0 closure** (`anvil-v0.4.0` 태그 `de82481` 이후, PR #18
  `726cbdc` + `18c7559`): 마지막 open gate(valid provider key `semantic` run + e2e
  step 59)가 OpenAI `gpt-4o`로 닫혔다(full e2e `343✓/0✗`, step 59 skip 없이 실행).
  post-release backlog도 정리됐다 — #37(GC-abort `Protected` 보존, `9e2a33d`)·#36(MCP
  `initialize`-error genericization, `ae96c34`)·#19(`config_api.go` surface별 분할,
  `a01d8da`) 완료, web npm audit는 breaking major만 남겨 defer(`a0fc935`), #7(reRestore
