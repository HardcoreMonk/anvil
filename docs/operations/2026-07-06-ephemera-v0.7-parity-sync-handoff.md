### end-user installer — runtime/operator surface

`install.sh` / `uninstall.sh` / `INSTALL.md` / `ephemera.service.in`와 release
workflow(`scripts/build_release.sh`)는 **ephemera daemon을 위한 runtime/operator
installer**이며 anvil/IronClaw product wrapper가 아니다. systemd service는 canonical
`ephemera` 이름을 유지한다(rule-permitted, anvil alias wrapper 없음;
`EPHEMERA_HOME=@DEST@`).

- release build integrity: `build_release.sh`가 다운로드한 kernel/firecracker를
  `main.go`에서 parse한 pin과 `sha256sum -c`로 검증한다. runtime `EnsureKernel`이 기존
  파일을 `os.Stat`로 skip하던 FULL-tarball supply-chain gap을 닫는다.
- `uninstall.sh`는 ephemera-scoped `/tmp` scratch를 root-gated·prefix-anchored로
  정리한다(의도된 cleanup). `/tmp/goose-rootfs` 항목은 현재 source에 producer가 없는
  stale no-op이다.
- 외부 Web UI 노출은 reverse proxy/TLS 또는 private network 뒤에서만 한다.

### conversation transcript restore

daemon proxy `GET /vms/{id}/sessions/{name}/transcript`(bearer)가 대화 transcript를
복원한다. agent export는 read-only `goose session export`(model call 없음)이고 응답
schema `{turns:[{role,text}]}`는 auth-free여서 Web UI가 daemon token 없이 렌더한다.

**4 transcript-safety guard(TDD):**

1. endpoint는 bearer 없으면 `401`.
2. payload는 provider key / CP token / `agent_token` sentinel-free.
3. cache-hit는 agent spawn 없이 serve.
4. export argv는 `session export -n {name} --format json`이며 run-token을 거부한다.

### upstream hardening reconcile — backport 승리

사전 독립 backport 3종이 upstream `v0.7.0` 버전을 이기고 single definition으로 남았다
(anvil이 stricter, **net Go diff는 doc-comment-only**):

- kernel SHA atomic verify(temp+rename, 무조건 검증 — upstream보다 strict)
- `resolveWorkDir` / `EPHEMERA_HOME`
- `waitForAgent` per-probe timeout(deadline cap)

기존 anvil adaptation(agent-stamp mount skip, restore-over-`meta.DiskPath`, proxy
`DisableKeepAlives`)은 하나도 rollback되지 않았다.
