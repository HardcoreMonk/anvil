# anvil v0.3.0 release candidate handoff

## 상태

- 작성일: 2026-05-26
- 작업 branch: `sync/ephemera-v0.3.6`
- 기준 공개 release: `anvil-v0.2.0`
- 다음 후보 release tag: `anvil-v0.3.0`
- upstream runtime baseline: ephemera `v0.3.6`

`anvil-v0.3.0` 후보는 `anvil-v0.2.0` 이후 누적된 runtime baseline 업데이트와
anvil product 변경을 하나의 product release로 묶는다. release note에서는 upstream
ephemera runtime 변경과 anvil 고유 변경을 분리해 기록한다.

## 포함 범위

- upstream ephemera `v0.3.2`-`v0.3.6` runtime baseline
  - live VM cold-restart와 `vms/<vm_id>/state.json`
  - watchdog dead persistence, per-agent restart, in-VM CP token injection
  - `EPHEMERA_API_TOKENS_FILE`, SIGHUP CP-token vsock fan-out
  - `/metrics`, `/vms/{vm_id}/stats`, `log/slog`, observability demo
  - autonomous webdev demo, in-VM `gtcall`, multi-line-safe `gtwall`,
    Goose JSON output parsing
- anvil script-only workload runner
  - guest `POST /workloads/run`
  - daemon `POST /vms/{vm_id}/workloads/run` proxy
  - deterministic nginx/Go HTTP workload E2E
- anvil deploy/operations hardening
  - VM callback networking fix
  - deploy gate scripts and systemd scheduler install assets
  - release secret scan helper
- 문서 정합성
  - `CONTEXT.md` runtime baseline 정정
  - public release boundary, ADR index, upstream sync policy, release checklist 갱신
  - `docs/analysis/09-v0.3.6-upstream-change-review.md` 추가

## 제외 범위

- upstream `main`의 `v0.4.0` PR-A storage/recovery 변경
- `webdev_demo.sh`를 IronClaw MCP public tool로 승격하는 작업
- scheduler service production deployment automation
- cross-host snapshot replication
- scheduler-aware cross-host flock placement
- L7 egress proxy/SNI hardening
- snapshot storage quota dashboard

```bash

go build ./cmd/goose-daemon

go build ./cmd/anvil-scheduler
bash -n webdev_demo.sh
bash -n scripts/build_image.sh

git diff --check
bash scripts/secret-scan.sh
```

KVM 검증:

```bash
go build -o anvil-daemon ./cmd/goose-daemon/
sudo -n bash e2e_test.sh
sudo -n bash scripts/vm-workload-e2e.sh
```

- `sudo -n bash e2e_test.sh`: 전체 단계 통과
- real-LLM `/tasks` smoke: provider key가 없어 skip
- `/metrics`, `/vms/{vm_id}/stats`, SIGHUP CP-token rotation: 통과
- `sudo -n bash scripts/vm-workload-e2e.sh`: 통과
- workload artifact: `/tmp/anvil-workload-e2e-20260526-171326`
- `bash scripts/secret-scan.sh`: tracked tree `PASS`
- secret scan 주의: git history는 과거 secret-like fixture/history로 `WARN`, local
  ignored `goose-secrets.yaml` 계열도 존재하므로 공개 release 전 rotate/비공개 보관
  상태를 별도 확인한다.
